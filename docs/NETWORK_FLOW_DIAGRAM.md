## 2. 请求流向图

### 2.1 生产环境 (推荐)

```
用户浏览器
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    反向代理 (443)                           │
│                                                             │
│  / → app:3000 (前端)                                       │
│  /api/v1/* → app:3000 → app:3001 (Next.js 代理)           │
│  /socket.io → app:3000 → app:3001 (WebSocket 代理)        │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────┐
│    app      │
│             │
│ 前端: 3000  │
│ 后端: 3001  │
└─────────────┘
    │
    ├─ 数据库查询 → postgres:5432
    ├─ 缓存操作 → redis:6379
    └─ MCP 调用 → mcp-server:3002
```

### 2.2 开发环境

```
用户浏览器
    │
    ├─ http://localhost:3000 → app:3000 (前端)
    ├─ http://localhost:3001 → app:3001 (后端API)
    └─ ws://localhost:3001 → app:3001 (WebSocket)
    │
    ▼
┌─────────────┐
│    app      │
│             │
│ 前端: 3000  │
│ 后端: 3001  │
└─────────────┘
    │
    ├─ 数据库查询 → postgres:5432
    ├─ 缓存操作 → redis:6379
    └─ MCP 调用 → mcp-server:3002
```

## 4. 端口映射表

```
宿主机端口    →    容器端口    →    服务
─────────────────────────────────────────
3000        →    3000        →    前端
3001        →    3001        →    后端API
5432        →    5432        →    数据库
6379        →    6379        →    缓存
3002        →    3002        →    MCP服务
```
